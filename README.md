# Telegram-бот «Магазин картин»

## О проекте
Pet-проект по разработке Telegram-бота для продажи картин. Бот позволяет пользователям просматривать каталог, добавлять картины в корзину и управлять заказами. Администратор может добавлять и редактировать товары в базе данных

## Инструменты
*   **Язык:** Python
*   **Библиотеки:** aiogram (Telegram Bot API), SQLAlchemy (ORM)
*   **База данных:** SQLite

## Архитектура базы данных
Проект использует реляционную БД с 5 таблицами:

1.  **`user`** - хранит информацию о пользователях (id, user_id, first_name, last_name)
2.  **`product`** - хранит каталог картин (id, name, description, price, image, category_id, quantity)
3.  **`cart`** - связующая таблица для корзины (id, user_id, product_id, quantity)
4.  **`banners`** - хранит баннеры (id, name, image, description)
5.  **`category`** - хранит категории товаров (id, name)


## Функционал

### Для пользователя:
*   Просмотр каталога картин
*   Добавление одной или нескольких картин в корзину
*   Удаление товаров из корзины
*   Просмотр содержимого корзины

### Для администратора:
*   Добавление новых картин в базу данных
*   Редактирование информации о существующих картинах
